# XMenz Landing Page

Landing page sederhana untuk XMenz, streamer gaming. Halaman ini menampilkan hero dengan avatar, tombol ke platform utama (Saweria, YouTube, TikTok), efek animasi ringan, serta popup info untuk kanal yang belum aktif.

## Fitur

- Hero animasi dengan avatar mengambang dan efek glow.
- Tombol link utama dengan animasi border/mask dan efek ripple pada klik.
- Popup informasi untuk kanal yang belum aktif.
- Tailwind CDN, jadi tidak perlu build tools tambahan.

## Cara Menjalankan

1. Buka langsung [index.html](index.html) di browser, atau
2. Jalankan server statis sederhana (contoh: `npx serve .` atau `python -m http.server 8000`) atau gunakan extention live server.

## Struktur Proyek

- [index.html](index.html): markup utama dan gaya tambahan.
- [assets/script.js](assets/script.js): logika popup, ripple effect, dan parallax logo.
- assets/: aset gambar/icon pendukung.

## Penyesuaian Cepat

- Ubah tautan platform di tombol utama/popup dalam [index.html](index.html) sesuai akun terbaru.
- Sesuaikan teks hero atau warna gradasi di bagian judul jika branding berubah.
- Tambah/ubah ikon mengambang dengan mengganti URL gambar di [index.html](index.html).
